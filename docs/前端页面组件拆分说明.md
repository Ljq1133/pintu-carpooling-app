# 拼图 PinTu 前端 UI 组件拆分说明

## 1. 使用目的

这份前端代码主要用于给前端设计和页面编写同学做参考，不是最终完整页面。

当前重点是：

- 统一视觉风格
- 明确基础 UI 元素
- 明确可复用组件边界
- 给后续页面开发提供组件示例

具体业务页面的细节、接口联调和交互流程，可以由前端编写同学在此基础上继续细化。

## 2. 设计风格

整体风格参考概念图：

- 极简
- 几何
- 高对比
- 强行动导向
- 绿色出行
- 拼图匹配感

品牌核心符号是“拼图 + 小车”，表达多人拼车、资源组合和绿色出行。

## 3. 色彩规范

| 名称 | 色值 | 用途 |
|---|---|---|
| 亮眼绿 | `#39FF14` | 主行动按钮、选中状态、绿色出行强调 |
| 主色黑 | `#111111` | 标题、主文字、黑色按钮、强对比背景 |
| 辅助灰 | `#757575` | 次级文字、说明文字、未选中图标 |
| 分割色 | `#E3E5E5` | 卡片边框、输入框边框、列表分割线 |
| 背景白 | `#FFFFFF` | 页面背景、卡片背景 |

建议不要额外扩展过多颜色，避免破坏统一感。

## 5. 页面骨架建议

当前代码只提供 3 个页面骨架示意：

| 页面 | 推荐组件 |
|---|---|
| 乘车页 | `LocationFields`、`MatchCard`、`PrimaryButton`、`BottomNav` |
| 订单页 | 状态 Tabs、`OrderCard`、`BottomNav` |
| 我的页 | 用户信息区、`StatStrip`、`ProfileMenuItem`、`BottomNav` |

登录页、开车页、后台管理页可以继续沿用同一套基础组件进行扩展。

## 6. 后续开发建议

前端同学后续细化页面时，建议遵守以下原则：

- 主按钮统一使用亮眼绿
- 重要标题和强提示使用黑色
- 卡片圆角控制在 8px 左右
- 页面尽量保持留白和清晰层级
- 订单、行程、匹配信息优先用卡片承载
- 页面底部导航保持四栏结构
- 拼图元素只作为品牌和匹配状态的视觉提示，不要过度装饰

## 7. 运行方式

进入前端工程目录：

```bash
cd pintu-frontend
npm install
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```
